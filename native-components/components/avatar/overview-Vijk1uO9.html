Types

There are three types of avatars: Default (fallback), Image, and Overflow.

Size Large Configuration Image

Anatomy & Size

 

Anatomy

An avatar contains a container and content inside, which can either be imagery (user-added photo, default imagery, or sponsored business logo ), text (overflow), or default illustration (for cases a default image is not provided).

 

Size

There are four core avatar sizes on native platforms.

They are 24, 32, 48 and 72.
