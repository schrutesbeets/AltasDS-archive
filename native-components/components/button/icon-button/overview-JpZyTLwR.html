Icon Button

Icon buttons help users take supplementary actions in a compact area.

  • Dos & Don'ts

Guidelines

Use icons buttons to display actions within a compact layout. The icon must visually communicate the button’s action. Icons can be grouped together or stand alone. They represent opening actions or represent binary actions that can be toggled on and off.

 

 

 

Types

There are four types of icon buttons: Contained, Standard, Floating, and Secondary

Anatomy & Size

All icon buttons require an icon. Containers are only visible in contained buttons.

 

Large

The minimum tap target for icon button are 48x48px even though it may have a smaller visual appearance.

 

Small

The minimum tap target for icon button are 48x48px even though it may have a smaller visual appearance.

 

 

 

States & Appearance

 

States

Icon buttons use state layers for interaction states. The available states are enabled, pressed, focused, and disabled.

 

Dark mode

Standard and secondary icon buttons flex across modes, while contained and floating icon remain fixed.
