Category Chip

Category chips represent a set of mutually exclusive options, allowing users to select a single choice from the set.

  • Overview
  • Dos & Don'ts

Properties

 

Leading icon

Category chips can have optional leading icons. Leading icons must reinforce the chip’s content as specified.

 

Label

A label is required for all category chips. They represent a single attribute, typically expressed as a noun or adjective.

 

Close icon

Selected category chips have a trailing close icon when there are a subset of secondary level filter chips.


In this case, the leading icon will disappear, then reappear when deselected.

 

 

 

Usage

 

Single select

Category chips are used for single selection. Selecting a chip automatically deselects all others.

 

If a user starts a new session, the default chip will be selected. We will not hold memory of their last selected chip.

 

Categories

A category chip can expand to show a related set of subcategory chips, enabling more detailed filtering.

 

 

 

Behavior

 

Horizontal scrolling

Chips scroll horizontally to allow for overflow.

 

Vertical scrolling

Chip rows are fixed to the header to allow content to scroll beneath.

 

 

 

Best practices

 

Content length

Do

Do use short, succinct labels to ensure that they are visible without truncation.

Don't

Avoid using long labels or truncating the content within chips.

 

Stacking

Do

Only use a single row of chips.

Don't

Do not stack various chip rows.

 

Default chip

Do

The default pre-selected chip should be the most common or recommended choice..

Don't

Do not make the default chip the least common choice.
