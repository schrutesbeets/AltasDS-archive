Merchandising Label

Merchandising labels highlight promotions, deals, or special features to attract users to a point of interest (POI).

  • Overview
  • Dos & Don'ts

Properties

 

Label text

Label text is required and should be short, attention-grabbing text strings used to highlight key offers, promotions, or contextual details within the experience. Label text should always be sentence case, unless it’s a proper noun.

 

Info icon

The info icon is used for geo’s that are required by law to show more information about sponsored products: France, Italy, Germany, Spain, Austria, Belgium (both languages), Netherlands, Sweden, Greece, Denmark, Norway, Switzerland, Portugal.

 

 

 

Usage

 

Primary label

Primary labels are only in use on B2B.

 

Secondary label

Secondary labels are used to highlight a POI and help it stand out, particularly when displayed in list or card layouts.

 

Accent label

Accent labels are used for price-related merchandising. These labels appear in red to reinforce their connection to strikethrough pricing, creating a clear visual association between the label and the reduced price.

 

Sponsored label

The sponsored label is used for sponsored content only.

 

Rewards label

The rewards label is used for membership program related discounts or sales.

 

Michelin label

The Michelin Label is used to highlight Michelin awarded restaurants.

 

 

 

Behavior

 

Hierarchy

There can be at most up to two labels per card, this is called a label row. When there are two labels, discounts take precedent over general merchandising.

 

Layout

Labels must always be used in a horizontal layout.

 

 

 

Best practices

 

Placement

Do

Keep merchandising labels above card titles.

Don't

Don’t move the position of the merchandising label.

 

Styling

Do

Use sentence case for labels unless a proper noun.

Don't

Do not use all caps or title case for label text.

Do

Keep labels their designated colors.

Don't

Do not update labels to custom colors. If you need to do so, please submit an intake form.

 

Number of labels

Do

Cards can only have up to two labels at most.

Don't

Do not include more than two labels.
