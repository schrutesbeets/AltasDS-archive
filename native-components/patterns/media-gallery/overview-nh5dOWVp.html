Media Gallery

A media gallery is a repeatable design pattern for displaying collections of images, videos, or other media in a structured and navigable layout.

  • Overview
  • Dos & Don'ts

 

 

 

Types

There are two types of media galleries: Standard and Mosaic.

 

Standard gallery

Mosaic gallery

 

 

 

Anatomy & Appearance

 

Standard gallery anatomy

The standard gallery is best for media of equal importance and accessibility. It has a uniform container size, ratio, and padding between media.

Media in a standard gallery comes in only one ratio, 1:1. The width of the viewport - minus the total gutter sizing (8px) all divided by three, the number of images per row.

 

Mosaic gallery anatomy

The mosaic gallery emphasizes certain items over others in a collection. It can create a hierarchy or a visually intriguing pattern using varied container sizes and ratios.

The sizes of media are organized into a repeating pattern.

 

Dark mode

Images remains the same across light and dark mode.
