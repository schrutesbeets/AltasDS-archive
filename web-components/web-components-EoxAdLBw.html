Web Components

Atlas provides an extensive set of components for use in building larger web experiences and patterns.

Supported Components

Supported components are in greater parity between Figma and web code. They are currently being optimized by the DS team, and are intended to receive ongoing bug and contribution support.

Avatar

A graphical representation of a user: usually a photo, illustration, or initial.

Buttons

Buttons are controls that let users take action, make choices, and move forward. Also known as action, call to action, or CTA.

Checkbox

An input for choosing from predefined options. When used alone, it gives a binary choice (checked/unchecked).

Checkbox with Label

A checkbox accompanied by label text.

Collapsible List

A list of topic titles that reveal or hide associated sections of content.

Also know as Accordion, Arrow toggle, Expander

Collapsible Text

The combination of a text block and button, used to truncate content when collapsed and reveal content when expanded

Facepile

The representation of multiple traveler identities.

Horizontal Scroll Bar Button

The combination of Circular Button and a gradient used to scroll elements within a row, bar, or carousel.

Image

An element for embedding images of fixed proportions.

Inline Alert

A way of informing the user of important changes in a prominent way.

Also known as Notification, Feedback, Message, Banner, Callout

Modal

A modal is an interface element that appears over other content. It requires an interaction from the user before they can return to whatever is underneath.

Also known as Dialog, Popup, Modal Window

Progress Bar

A representation of a user’s progress through a series of discrete steps. Also known as Progress Tracker or Progress Meter

Selector

A toggle button used for single and multi-selection inputs, specifically within question and answer flows.

Sheet

A panel which slides out from the edge of the screen.

Also known as drawer or tray

Slider

A form control for choosing a value within a preset range of values.

Also know as a Range Input.

Spinner

A visual indicator that a process is happening in the background but the interface is not yet ready for interaction.

Also known as Loader, Loading

Switch

A control used to switch between two states: often on or off.

Also known as Switch, Lightswitch, Toggle button

Switch Row

A text label and/or description, accompanied by a Switch.

Stepper with Label

A control for editing a numeric value with buttons for decrementing / incrementing.

Tab Bar

Tab Bars are a way of navigating between multiple panels, reducing clutter and fitting more into a smaller space.

Also known as Tabbed Interface

Text Links

A link is a reference to a resource. This can be external (e.g. a different web page) or internal (e.g. a specific element in the current document).

Also known as Anchor, Hyperlink

Toast

A type of alert which appears in a layer above other content, visually similar to a mobile or desktop push notification.

Also known as: Snackbar, Alert

Tooltip

Tooltips are small overlays that appear when users hover over, focus on, or tap an element. They provide context or explain the function of a piece of UI.

Also known as Screentip, Infotip, Hint

 

Frozen Components 🥶

Frozen components require a larger investigation of parity between Figma and web code. They are not currently scheduled to be redesigned, or receive bug or contribution support. Please use with discretion.

Contributor 🥶

The combination avatar, name and number of replies representing a user's contribution to a review or topic.

Contributor Bio 🥶

The combination of avatar, name and biography displayed for authors of curated content and longer texts associated with a contributors.

Dot pagination 🥶

Pagination is used for splitting up content in a series or collection into several pages. Dot Pagination provides navigation for the paged information, and helps ground users while providing context about the paged collection.

Dropdown Input Field 🥶

A Dropdown Input Field is a compact element that allows users to quickly select single or multiple values from a list of options.

Also known as Dropdown, Dropdown Menu, Dropdown Overlay

Filter Chip Row 🥶

A row of chip inputs used for filtering content.

Flyout 🥶

{ Definition of the component in 1 sentence. }

Also known as Tray, Drawer, Sheet, Panel

Forum Cards 🥶

Forum Cards are used on Tourism pages to display content from the forum.

Full Image Feature Card 🥶

A card featuring an image as the entire background.

Histogram 🥶

The histogram diagram is used to display different rating intervals that make up a total review count.

Horizontal Card 🥶

Horizontal cards are used to display summarized content or POIs in a compact, side-by-side layout, making them ideal for areas where vertical space is limited.

Image Background Card 🥶

The Image Background Card contains a title as well as an image or illustration that together communicates the destination the user will be taken when tapping on the card.
Also known as: cover photo, category photo, geo cover.

Image Scrim 🥶

A temporary field of color applied directly on top of an Image, to provide accessible color contrast with text appearing on top of the image.

Inset Image Feature Card 🥶

A card containing an inset image, Bubble Ratings, Buttons and other text content, supported in a variety of background colors.

Label 🥶

Contained text positioned in close proximity to another component, representing a status, property, or some other metadata.

Labeled Input Field 🥶

The Labeled Input Field features a persistent, internal label. It uses a dropdown menu to allow users to enter or select values.

Also known as Input, Input Field

Menu Container 🥶

A container for menus who's options are hidden by default but can be shown by interacting with a button.

Michelin Label 🥶

The Michelin Label is used on cards and shelves (on list pages in particular) to highlight Michelin awarded restaurants.

Modal Scrim 🥶

A temporary field of color applied directly behind a Modal to obscure interaction with the rest of the page.

Multi Input Field 🥶

Multi Input Fields allow users to enter the number of guests, specify the number of rooms, and select a date or a range of dates at the same time.

Also known as Input Entry Points, Input Boxes, Input Row

No Image Card 🥶

Cards with no image are best suited for cases that display large amounts of information to a user, such as heterogeneous search results.

Number Labels 🥶

Number Labels can be found on cards and on itinerary pages on Experiences. They are used to indicate which number stop the location is on the route.

Also known as Step Label

Number Pagination 🥶

Pagination provides navigation for paged information.

Page Error states 🥶

An Error State occur when the system fails to complete an expected action. The error state informs users and can contain critical information, require decisions, or involve multiple tasks.

Search Field 🥶

Search inputs allow users to find content by entering a search term.

Also known as Combobox, Search Bar, Search

Single Input Field 🥶

Single Input Fields allow users to enter the number of guests, specify the number of rooms, or select a single date or a range of dates.

Also known as Input Entry Point, Input Box, Input

Skeleton 🥶

A placeholder layout for content which hasn't yet loaded, usually built up of grey boxes.

Also known as Skeleton Loader

Special Rate Label 🥶

The special rate label is used as an indicator that there is a special rate associated with an item. The label has an optional icon and is clickable so the user can learn more about the special rate.

Stacked Chip Carousel 🥶

One or more stacked Filter Chip Rows.

Tags 🥶

Tags are keywords that categorize content with other, similar content. They are defined by the data they hold, which can span multiple categories.

Text Area Text Field 🥶

Text fields let users enter and edit text. Text areas are fixed height fields that can scroll when the user’s input exceeds the text area’s height.

Also known as Text Area, Text Field

Text Fields 🥶

Single Line Text fields allow users to input and edit one line of text. They typically appear in forms and dialogs.

Also known as Text Input, Text Input Field

Text Menu 🥶

A menu in which actions or navigation options are hidden by default but can be shown by interacting with a button.

Typeahead Results 🥶

Typeahead results are interactive pieces of UI that contain content that is created by search engines in response to a query.

UGC Cards 🥶

Cards that contain user generated content.

Value Prop Message 🥶

A Value Prop Message is a UI component with a unique visual treatment that draws user attention to its content. It is used to emphasize a specific feature of a product or a process.

Also known as Product Highlight or Product Callout

Vertical Card 🥶

Vertical cards are used to display a summarized collection of news, content, or a POI.
